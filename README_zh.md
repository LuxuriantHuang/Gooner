# 沉浸式 AI 桌面伴侣 (Gooner) - 新手指南与功能介绍

欢迎使用本软件！这是一款专注于**视觉沉浸、AI 互动与行为调度**的桌面级应用程序。
通过高度可定制的定时弹窗、动态壁纸、AI 对话以及深度的视觉干预功能，它可以将你的桌面环境改造为一个完全沉浸、甚至是带有“强制性”的私人空间。

无论是用于轻度的桌面美化，还是深度的沉浸式调教，这款软件都能完美胜任。

---

## 🌟 核心亮点

1. **开箱即用，内置成熟预设**：安装即自带作者精心调教的四套配置（默认模式、工作专注、休闲摸鱼、疯狂模式），无需复杂设置即可体验。
2. **多源媒体混合调度**：支持本地图片、视频文件夹，同时也支持无缝弹出预设好的网站链接库。
3. **强大的 AI 伴侣**：接入 DeepSeek 等大语言模型，弹窗不再是冰冷的图片，AI 会结合当前画面对你进行智能的嘲讽、挑逗或指引。
4. **极端的视觉与精神干预**：包含屏幕幽灵残影（Ghost）、X光透视（X-Ray）、满屏瀑布流（Waterfall）、以及洗脑式的精神污染文本词库。
5. **进程级强控守卫**：可以通过黑白名单监控你的软件使用，一旦打开“禁忌软件”，强制执行弹窗或惩罚。

## 🚀 快速上手指南

### 第一步：选择适合你的“姿势”（配置档案）
第一次打开软件时，系统已自动为你内置了 4 套成熟的预设：
- **默认模式**：功能全面，适合日常体验与 AI 互动。
- **工作专注 (Work Focus)**：非常克制的模式。极低的弹窗频率（约45分钟一次），弹窗寿命仅1分钟，适合在工作间隙提供极其轻微的点缀。
- **休闲摸鱼 (Casual Relax)**：中等频率（15分钟左右），会有多个弹窗连发，适合放松时的娱乐。
- **疯狂模式 (Insane Popups)**：极高频率的轰炸，无上限的窗口堆叠，配合长时间的弹窗寿命，适合需要彻底丧失注意力的极限体验。

*操作路径：左侧导航栏 -> 【全局与基础】 -> 在顶部下拉框切换配置档案。*

### 第二步：投喂你的“内容库”
软件的弹窗内容依赖于你提供的数据。
- **本地文件**：添加你喜欢的图片、视频所在的文件夹。
- **网站库**：你可以将喜欢的网页链接逐行录入，软件会在弹窗时通过浏览器打开它们。
- *操作路径：左侧导航栏 -> 【媒体与内容源】。*

### 第三步：唤醒 AI 伴侣（强烈推荐）
如果没有 AI，它只是一个普通的弹窗播放器。有了 AI，它将拥有灵魂。
1. 前往 DeepSeek 官网（或其他兼容 OpenAI 格式的厂商）获取一个 `API Key`。
2. 填入软件，并在“AI 对话设定”中填写你想赋予它的身份（如：高冷女王、贴心女友等）。
3. *操作路径：左侧导航栏 -> 【AI 伴侣】。*

## ⚙️ 七大功能模块详解

为了让你不被复杂的设置绕晕，软件的所有功能被清晰地划分为了 7 大分类：

### 1. ⚙️ 全局与基础
一切开始的地方。你可以在这里**切换配置档案（Profile）**、修改软件的 **UI 主题颜色**、更改软件语言，以及设定**快捷键**（如一键隐藏所有弹窗、一键强制关闭等）。强烈建议先熟悉快捷键，以备不时之需！

### 2. ◫ 媒体与内容源
决定了弹窗会“弹出什么”。
- **本地文件夹**：支持多文件夹管理。
- **网站库**：可以批量编辑要弹出的网址链接。
- **桌面壁纸自动更换**：不仅是弹窗，你的桌面壁纸也可以被软件接管，按频率自动切换。

### 3. ◷ 调度与触发
控制弹窗“什么时候出现”以及“一次出现多少”。
- **调度频率**：支持复杂的随机化设置，比如“每 10 分钟触发一次，但会有 ±3 分钟的随机波动”。
- **进程规则守卫**：你可以设定“白名单”或“黑名单”。例如，设定只在打开 `chrome.exe` 时允许弹窗，或者一旦发现你打开了某些工作软件，就立刻执行强行停止或爆发弹窗。

### 4. ✦ 窗口与外观
决定弹窗“长什么样”。
- **窗口属性**：全屏透明、置顶、防点击穿透等硬核设置。
- **多显示器支持**：让弹窗只在副屏出现，或在所有屏幕上群魔乱舞。
- **关闭按钮**：甚至可以把关闭弹窗的按钮做成“极难点击的随机逃逸按钮”。

### 5. ✎ AI 伴侣
控制 AI 的大脑。
- 支持高度自定义的 Prompt（系统提示词），你可以塑造任何你想要的 AI 性格。
- 设定弹出界面的 UI 风格（黑客风、霓虹风、暗黑风）。

### 6. ☣ 沉浸与惩罚 (核心高阶玩法)
如果你觉得普通的弹窗太无聊，这里是进阶体验区：
- **视觉干预 (Visual Interventions)**：
  - `Ghost` (幽灵模式)：将图片变成巨大的半透明残影覆盖整个屏幕。
  - `X-Ray` (透视模式)：鼠标变成一个放大镜，走到哪里，屏幕底下就会透视出背后的隐藏画面。
  - `Waterfall` (瀑布流)：漫天飞舞的缩小版媒体瀑布雨。
- **精神污染 (Pollution)**：通过剪贴板篡改、随机文本输入等方式，强行向你输出特定词库中的文本，进行高强度洗脑。
- **极限控制 (Hardcore Mode)**：一旦开启，除非通过特殊的物理或复杂任务解除，否则你将无法关闭弹窗或修改设置。**新手请谨慎开启！**

### 7. ◩ 生涯记录
记录你使用本软件的各项数据：总运行时长、沉浸时间、弹窗被展示了多少次等，为你颁发荣誉徽章与成就盖章。

## ⚠️ 安全与注意事项

1. **隐私安全**：本软件是一款纯本地运行的桌面程序。除了调用您指定的 AI 大模型 API 外，**不包含任何网络遥测、后台上传功能**，您的本地图片和数据绝对安全。
2. **防卡死提示**：如果您启用了 `Hardcore (极限模式)` 并且隐去了关闭按钮，当遇到紧急情况时，请使用您在【全局与基础】中设置的**一键全关快捷键**，或者直接通过任务管理器结束进程。
3. **性能建议**：如果开启了大量的全屏 `Ghost` 或高频视频弹窗，可能会占用一定的显卡性能。如果出现画面撕裂或卡顿，请在【调度与触发】中适当降低“最大窗口并发数量”。
